# 📘 Blog Management System

A full-featured **Blog Management System** built with **ASP.NET Core (.NET)** following **Clean Architecture**, **Repository Pattern**, and **Unit of Work** principles.  
The system includes role-based authentication, authorization, blog & category management, user management, logging, and advanced admin features.

## 🚀 Project Overview

This project is designed to manage blogs with a secure admin dashboard and a public client interface.  
It supports **role-based access control**, **claims-based permissions**, **server-side pagination**, **search functionality**, and **user activity tracking**.

---

- Repository Pattern
- Unit of Work Pattern
- Service Layer
- Dependency Injection
- Separation of Concerns
